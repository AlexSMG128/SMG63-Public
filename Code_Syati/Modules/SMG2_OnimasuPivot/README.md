# SMG2 OnimasuPivot
### From Super Mario Galaxy

This module allows you to use the special Tox Box variant that was used in Toy Time Galaxy in SMG1.

Below is a list of everything included:
- The "OnimasuPivot" Object in the editor.
> *Note: Path setup works the same as it did in SMG1*

Below is a list of other things that you will need:
- A level editor

## Credits
- @superhackio - Ported the SMG1 code to SMG2 & added SMG2 specific slowdown switch functionality.

## Features
- Supports the new Obj Args that were added to [`OnimasuJump`](https://smgcommunity.github.io/galaxydatabase/config_OnimasuJump.html ) in SMG2
- Supports the Slowdown switch
- No file setup required.
  - SMG2 has everything needed already, so you can just place `OnimasuPivot` and be good to go.
